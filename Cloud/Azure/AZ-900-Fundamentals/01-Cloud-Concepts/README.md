# 📌 Overview

Cloud concepts are the foundation of modern cloud engineering and infrastructure operations.

This section covers:

- Cloud service models
- Cloud deployment models
- Financial concepts
- Shared security responsibilities
- Enterprise cloud scenarios

---

# ☁️ Cloud Service Models

| Model | Managed By Provider | Managed By Customer |
|---|---|---|
| IaaS | Hardware, Networking | OS, Applications |
| PaaS | Infrastructure + Runtime | Applications + Data |
| SaaS | Entire Application Stack | Data & Access |

---

# 🏢 Cloud Deployment Models

| Model | Description |
|---|---|
| Public Cloud | Shared provider infrastructure |
| Private Cloud | Dedicated enterprise infrastructure |
| Hybrid Cloud | Combination of public and private |

---

# 💰 Cost Models

| Model | Description |
|---|---|
| CapEx | Upfront infrastructure investment |
| OpEx | Consumption-based operational expenses |

---

# 🔐 Shared Responsibility Model

Cloud security responsibilities are shared between:

- Cloud Provider
- Customer

Responsibility changes depending on:

- IaaS
- PaaS
- SaaS

> [!IMPORTANT]
> Customers are always responsible for identity and access management.

# 🧪 Real-World Scenarios

- Migrating on-premises VMs to Azure
- Deploying web applications using App Services
- Using SaaS collaboration platforms
- Hybrid identity integration

---

# 🚨 Common Misconceptions

| Misconception | Reality |
|---|---|
| Cloud is always cheaper | Poor architecture can increase costs |
| SaaS requires no security | Identity and data remain customer responsibilities |
| Hybrid cloud is simple | Networking and governance can become complex |

---

# ✅ Best Practices

- Understand responsibility boundaries
- Use least privilege access
- Monitor cloud spending
- Apply governance standards
- Document cloud architectures
