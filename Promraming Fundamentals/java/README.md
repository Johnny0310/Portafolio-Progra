# ☕ Java Fundamentals

This section contains notes and examples covering the core fundamentals of the Java programming language.

The goal of these files is to document the learning process while building a strong programming foundation.

---

# 📚 Topics Included

## 🔹 Variables

Learn how to declare and use variables in Java.

## 🔹 Data Types

Understand primitive and reference data types.

## 🔹 Conditionals

Practice decision making using:

* if
* else
* switch

## 🔹 Loops

Work with:

* for loops
* while loops
* iteration patterns

## 🔹 Functions

Learn how to create reusable methods and organize logic.

## 🔹 Arrays

Understand how to store and manipulate collections of data.

## 🔹 Error Handling

Introduction to:

* try/catch
* exceptions
* defensive programming
