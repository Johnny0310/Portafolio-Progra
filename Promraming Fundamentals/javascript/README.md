# 🧮 JavaScript Calculator App

A simple calculator application built with JavaScript.

This project was created to practice core JavaScript concepts, DOM manipulation, user interaction, and basic application logic.

---

# 🎯 Goal

The objective of this project is to demonstrate:

✅ JavaScript fundamentals
✅ DOM manipulation
✅ Event handling
✅ Mathematical operations
✅ Interactive UI behavior
✅ Basic frontend application structure

---

# 📚 What You Will Learn

🔹 Variables and functions
🔹 JavaScript events
🔹 Button interactions
🔹 Arithmetic operations
🔹 DOM updates
🔹 User input handling

---

# ⚙️ Features

➕ Addition
➖ Subtraction
✖️ Multiplication
➗ Division
🧹 Clear screen functionality

# 🛠️ Technologies Used
