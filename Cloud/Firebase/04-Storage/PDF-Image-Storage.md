# 📌 Overview

Firebase Storage is commonly used for storing media files such as images and PDF documents.

---

# 🖼️ Image Storage

Common image use cases:

- Product images
- Media galleries
- Content delivery

---

# 📄 PDF Storage

PDF use cases:

- Reports
- Invoices
- Documentation
- Contracts

# ⚙️ Optimization Strategies

> [!TIP]
> Optimized media reduces storage costs and bandwidth usage.

Recommendations:

- Compress images
- Use modern formats
- Limit file size
- Generate thumbnails
