# 📌 Overview

Firebase Cloud Functions enables developers to run backend logic in a serverless environment without managing infrastructure.

This module focuses on:

- HTTP functions
- Firestore triggers
- Authentication triggers
- Scheduled functions
- Deployment workflows
- Scaling strategies
- Production best practices
