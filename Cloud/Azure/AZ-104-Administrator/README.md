# 📌 Overview

This section covers Azure Identity and Governance administration tasks required for the AZ-104 certification and real-world Azure administration roles.

The content focuses on:

- Microsoft Entra ID administration
- Role-Based Access Control (RBAC)
- Azure governance
- Subscription management
- Resource organization
- Security administration
- Conditional Access
- Privileged Identity Management (PIM)
- Enterprise governance best practices
- Troubleshooting identity-related issues
