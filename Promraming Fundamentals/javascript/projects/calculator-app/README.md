# Scientific Calculator App

A scientific calculator web application built with HTML, CSS, JavaScript, and Bootstrap.

This project demonstrates frontend development fundamentals, DOM manipulation, event handling, and dynamic expression evaluation.

---

# Features

- Addition
- Subtraction
- Multiplication
- Division
- Parentheses support
- Decimal operations
- Clear all button (AC)
- Remove last character button (C)
- Scientific calculator layout
- Responsive design
- Dynamic expression evaluation

---

# Technologies Used

- HTML5
- CSS3
- JavaScript
- Bootstrap 5
- Visual Studio Code

# How to Run

1. Open the project folder in Visual Studio Code
2. Install the `Live Server` extension
3. Right click `index.html`
4. Select `Open with Live Server`
