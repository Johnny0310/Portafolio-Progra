# 📌 Overview

Cloud computing changes how organizations consume and pay for infrastructure resources.

Traditional datacenters often rely on:

- Capital Expenditures (CapEx)

Cloud platforms commonly use:

- Operational Expenditures (OpEx)

Understanding both models is essential for cloud architecture, budgeting, and financial planning.

---

# 💰 Financial Models

## CapEx

Capital Expenditure (CapEx) refers to upfront investments in infrastructure and hardware.

Examples:

- Physical servers
- Networking equipment
- Datacenter facilities
- Storage systems

### Characteristics

- Large initial investment
- Long-term asset ownership
- Predictable infrastructure lifecycle
- Higher maintenance responsibility

---

## OpEx

Operational Expenditure (OpEx) refers to ongoing consumption-based costs.

Examples:

- Azure Virtual Machines
- Azure Storage
- SaaS subscriptions
- Managed cloud services

### Characteristics

- Pay-as-you-go pricing
- Reduced upfront costs
- Flexible scalability
- Faster resource deployment

> [!NOTE]
> Most public cloud services use an OpEx consumption model.

---

# 📊 Comparison Table

| Feature | CapEx | OpEx |
|---|---|---|
| Initial Investment | High | Low |
| Ownership | Customer | Provider |
| Scalability | Limited | Flexible |
| Maintenance | Customer | Shared/Provider |
| Financial Model | Asset Purchase | Operational Spending |

# 🧪 Real-World Scenarios

| Scenario | Recommended Model |
|---|---|
| On-premises datacenter | CapEx |
| Startup infrastructure | OpEx |
| Enterprise cloud migration | OpEx |
| Long-term hardware investment | CapEx |
| Rapid workload scaling | OpEx |

# 🚨 Common Issues

## Poor Cloud Cost Management

### Possible Causes

- Unused virtual machines
- Overprovisioned resources
- Lack of governance
- Missing cost alerts

### Impact

- Increased monthly spending
- Budget overruns
- Resource waste

---

## Misunderstanding Cloud Savings

> [!WARNING]
> Cloud adoption does not automatically reduce costs.

Improper architecture or poor governance can increase operational expenses significantly.

---

# ✅ Best Practices

- Monitor cloud spending regularly
- Use Azure Cost Management
- Implement resource tagging
- Shut down unused resources
- Use reserved instances when appropriate
- Define governance policies
