This module introduces the foundational concepts required to understand Firebase as a modern Backend-as-a-Service (BaaS) platform.

Topics include:

- Firebase CLI
- Pricing model
- Environment setup
- Backend abstractions
- Cloud-native architecture
- Serverless development principles
