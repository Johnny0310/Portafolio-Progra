# Java Calculator

A simple console-based calculator built with Java.

This project was created to practice and demonstrate core programming fundamentals such as variables, conditionals, loops, functions, user input, and error handling.

---

# Features

- Addition
- Subtraction
- Multiplication
- Division
- Interactive menu
- Loop-based navigation
- Division by zero validation

---

# Technologies Used

- Java 21
- Visual Studio Code

# Concepts Practiced

This project demonstrates the use of:

# How to Run

## Compile

```bash
javac .\src\Main.java
```

## Execute

```bash
java -cp .\src Main
```
